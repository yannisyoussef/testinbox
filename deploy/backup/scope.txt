# The data-lifecycle contract for production backups (ADR-034 §5,
# docs/dev/production.md). EVERY table in the schema is classified here, and
# scripts/check-backup-scope.sh fails when the migrations contain a table this
# file does not name — a new table forces a decision, it cannot drift in.
#
#   +  durable control-plane state: backed up. Losing it loses tenant identity.
#   -  tenant content or transient state: NEVER backed up. Copying it would
#      retain message content past the ADR-009 TTL and past explicit deletion,
#      which is the promise the product makes to senders and tenants alike;
#      transient state is rebuilt by the running system.
#
# api_key holds verifiers only (ADR-032 §4): no plaintext credential can be
# recovered from a backup. idempotency_record carries request fingerprints and
# a projection of what a request created, including inbox addresses — content
# by another route, and it expires in hours.
+ workspace
+ project
+ api_key
+ exact_address_reservation
+ flyway_schema_history
- inbox
- message
- attachment
- idempotency_record
- rate_bucket
- wait_lease
# ADR-035 §14 (V6). All seven are derived or transient, so none is ever backed
# up. The ledger is rebuilt from rows, and after a restore `message` is empty,
# so empty base figures are correct. A reservation, an ambiguity or a latch
# describes object storage, which is not restored either (ADR-035 §9 restore
# procedure). scripts/check-backup-scope.sh refuses any of these as `+`.
- workspace_storage_account
- inbox_storage
- storage_delta
- storage_reservation
- storage_ambiguity
- storage_node
- storage_admission_latch
# ADR-035 §5 (V7). A clock-offset episode describes the reservations, which
# are not restored either.
- storage_clock_episode
# ADR-035 filesystem-containment contract (V8, TI-STORAGE-006E). Deletion
# debt describes trash on the MinIO filesystem, and an observation describes
# that filesystem at one instant; neither survives a restore meaningfully, and
# both are rebuilt by the next deletion and the next Ops observation.
- storage_deletion_debt
- storage_filesystem_observation
